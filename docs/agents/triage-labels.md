# Triage labels

Use these strings in the issue's `Status:` line when assigning a triage role.

| Canonical role | Tracker string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified; ready for autonomous implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

When a skill names a triage role, use its corresponding tracker string.
