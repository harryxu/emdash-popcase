# Open YouTube links with on-demand embeds

Extend ADR-0004's completed-page video link enhancement to individual YouTube `watch`, `youtu.be`, and Shorts links. Authors use ordinary text or image links without new blocks or settings. These occurrences join the existing ordered viewing group; downloads, visual editing, native players, and existing iframes keep their behavior. Other provider pages, playlists without a video, channel/live entry points, and YouTube embed URLs remain ordinary links.

Use a separate YouTube slide rendered through the existing lightbox's custom slide API. Mount a `youtube-nocookie.com` iframe only for the current, open slide, and remove it on navigation or close. This avoids background playback and third-party requests from carousel preloading. Do not load a provider SDK or fetch titles, dimensions, thumbnails, or embeddability metadata. Preserve author images for thumbnails and captions; text-only links use a play icon. Default to 16:9 for regular videos and 9:16 for Shorts, fitting the available viewport without cropping.

Attempt autoplay with sound and inline controls, without fullscreen. Preserve valid `t`/`start` offsets but control all other embed parameters locally. Each activation starts again at the specified offset. Keep the original URL and modified-click behavior. The 2026-10-23 layout refinement removes the separate external link below the player at the maintainer’s request; original entry links still provide no-JavaScript and failed-viewer navigation. Retain the provider's error UI without automatically redirecting. Send the origin referrer required by YouTube using `strict-origin-when-cross-origin`; privacy-enhanced mode does not mean zero third-party data collection. Keyboard events inside the cross-origin player belong to YouTube, while outer close/navigation controls remain available and dismissal restores trigger focus.

The same refinement reserves toolbar clearance and fluid surrounding insets based on the available slide dimensions, caps video width at 1280px, and reserves caption space separately. This keeps both landscape videos and portrait Shorts below the toolbar and gives large displays more breathing room without changing image slides or the thumbnail strip.
